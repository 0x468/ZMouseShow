# ADR 0001：平台、输入与渲染基线

- 状态：已接受
- 日期：2026-08-15

## 背景

ZMouseShow 需要在受限企业电脑上以免安装、无管理员权限的单文件 EXE 运行，并在多块高 DPI 显示器上快速定位鼠标。

## 决策

1. 使用 Visual Studio 2026、MSVC v145、CMake 4.4 和 C++23，仅构建 x64。
2. 使用 Raw Input 后台观察键盘和鼠标，不使用全局低级钩子。
3. 使用每显示器 Overlay 窗口，不使用一个虚拟桌面大小的 CPU 位图。
4. P0 先验证 Window Region 真圆孔与小型分层位图组合方案。
5. 如果 Region 方案的动画或兼容性不合格，保持 Overlay 管理接口并切换为 Direct2D + DirectComposition。
6. P0 使用内置默认配置和可选 TOML，不实现设置面板；采用 vendored toml++ 单头文件解析，托盘长期偏好以保留注释的原子写回持久化。
7. 不修改系统光标；放大效果通过 Overlay 绘制当前光标副本实现。

## 结果

- 运行时不需要第三方框架或外部运行时 DLL。
- 输入状态机和坐标逻辑可脱离 Win32 窗口进行单元测试。
- Region 路线需要在真实多屏、混合 DPI、任务栏和 120Hz 环境完成技术验证。
- DirectComposition 作为明确的替代方案，而不是首版同时维护的第二套实现。
