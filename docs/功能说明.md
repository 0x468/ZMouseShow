# ZMouseShow 完整功能说明

## 一、产品边界

ZMouseShow 用于在大尺寸、多显示器和高 DPI Windows 桌面上快速定位鼠标。项目坚持绿色、原生、离线和普通用户权限：单个 EXE、无安装器、无常驻服务、无网络请求、无 WebView 或托管运行时，不修改系统光标方案，也不注入其它进程。

局部放大屏幕内容的放大镜、主题编辑器、插件系统和 GPU 特效编辑器不属于 P3。

## 二、运行结构

程序由一个隐藏的 Win32 消息窗口协调，主要模块如下：

| 模块 | 职责 |
| --- | --- |
| 输入检测 | 从 Raw Input 维护按键/鼠标状态，识别双击 Ctrl、组合键和晃动。 |
| 激活策略 | 合并暂停、单次请求门、程序排除、全屏状态和触发来源。 |
| 显示拓扑 | 枚举显示器、工作区、虚拟桌面坐标和每屏 DPI。 |
| Overlay | 为每块显示器维护 Region 暗化窗口，并维护圆环、波纹、十字线和光标副本的小型分层窗口。 |
| 动画 | 使用单调时钟计算 220 ms 淡入淡出和单次波纹进度。 |
| 设置与配置 | 原生模态对话框、TOML 解析、兼容式迁移和原子保存。 |
| 托盘与单实例 | 提供常驻入口，并将重复启动的设置请求交给已有实例。 |
| 诊断 | 输出有效设置、注册状态和显示拓扑，不输出输入历史。 |

程序不建立持续高频渲染循环。只有效果出现、消失或波纹进行时才启用 8 ms 等待定时器；稳定显示后停止动画唤醒。

## 三、触发与仲裁

双击 Ctrl、自定义组合键和鼠标晃动是三个独立开关，不强制互斥。所有来源最终进入同一个激活门：已经暂停、托盘菜单或设置窗口打开、效果可见或请求已经排队时，后续请求直接忽略，因此同时启用不会叠加窗口或重复动画。退出模态界面后先同步当前物理按键状态，再从新输入开始识别。

双击 Ctrl 使用严格状态机，仅接受同一配置侧 Ctrl 的两次完整点击。任何其它按键、鼠标按键、滚轮或超时会重置候选序列。自定义组合键同时具有纯配置验证、设置时临时探测和运行期持续 `RegisterHotKey` 三层保护。晃动检测仅在所有主要鼠标键释放时采样方向反转，并具有阈值、时间窗和冷却期。

键盘触发与晃动触发在效果启动后不会互相再次唤醒；激活请求门在查询显示器和创建窗口之前生效。

## 四、全屏抑制与程序排除

全屏判断综合前台窗口扩展框架边界、当前显示器矩形和 `GetClipCursor` 结果。自动模式只抑制晃动，严格模式抑制全部来源，关闭模式不抑制。该结果是启发式状态，不宣称识别游戏。

程序排除使用前台进程的最终 EXE 文件名做规范化精确匹配，优先级高于全屏策略。配置拒绝路径、控制字符、非法 Windows 文件名字符、非 `.exe` 名称以及超过限制的列表。

## 五、显示与渲染

### 暗化与透明孔洞

每块显示器对应一个无激活、点击穿透的顶层暗化窗口。窗口通过 Win32 Region 表示“整屏减去高亮孔洞”，避免为整块 2K/4K 显示器维护逐像素 Alpha 位图。孔洞支持圆形、圆角方形和菱形，并按所在显示器 DPI 将 DIP 转换为像素。

### 定位视觉层

- 稳定描边使用预乘 Alpha 的小型 32 位 DIB，并与圆形、圆角方形或菱形孔洞保持一致；
- 启动波纹从基础半径向外扩散并淡出，形状与孔洞一致；
- 十字线只覆盖鼠标所在显示器的局部范围，以黑色外沿配白色内芯适配明暗背景；
- 放大光标通过当前 `HCURSOR` 在黑底和白底分别绘制后重建 Alpha，显示在独立分层窗口中；放大层可用时通过 Magnification API 临时隐藏原光标，退出效果时恢复；
- 所有视觉层均点击穿透、不可激活，不调用 `SetSystemCursor`。

动画期间按最大需要尺寸一次分配 DIB/DC，逐帧只擦除旧圆周并绘制新圆周，再调用 `UpdateLayeredWindow`。不逐帧创建窗口、DC 或 DIB。动画进度来自单调时钟；系统繁忙时跳过中间状态，而不是延长遮罩持续时间。

### 多屏与 DPI

使用虚拟桌面坐标，支持负 X/Y、显示器纵向错位、不同缩放比例和动态拓扑变化。显示变化后重建每屏暗化窗口；鼠标跨屏时将孔洞和局部特效迁移到对应显示器。`--simulate-displays` 提供三屏几何预览，但不模拟真实 DWM、显卡驱动或混合刷新率。

## 六、设置、持久化与回退

TOML 是唯一持久化来源，设置窗口只是受约束的编辑入口。字段缺失或单个字段非法时使用默认值；TOML 语法错误时拒绝整份文件。旧文件不需要版本升级步骤：新字段在加载时按默认值补全，保存时追加，同时保留注释、未知字段和未知表。

晃动灵敏度滑条把 1–10 映射到累计位移阈值，默认 5 对应 1000；其它时间窗、路径比、反转次数和冷却期仍保留为 TOML 高级参数。“恢复默认配置”将可见选项与这些高级参数一并重置为草稿，只有应用成功后才写入文件。

保存过程先在内存修补并重新解析候选内容，再写同目录临时文件并原子替换。自定义组合键、当前用户自启动和运行时设置在成功路径上一起提交；失败时保留上一组有效运行状态，并尽力恢复自启动登记。诊断同时报告期望状态和实际状态，避免静默失败。

## 七、托盘、单实例与自启动

命名互斥体限制当前会话只有一个实例。第二次启动会寻找已有消息窗口；带 `--settings` 时向已有实例发送打开设置的请求。托盘随 Explorer 的 `TaskbarCreated` 消息自动恢复。

登录自启动只使用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ZMouseShow`，值为带引号的当前 EXE 完整路径。程序不创建计划任务、服务或系统范围登记。

## 八、安全与隐私

- Raw Input 数据只在内存中用于当前状态机；
- 不记录按键序列、鼠标轨迹、窗口标题或屏幕截图；
- 只为排除策略临时查询前台进程 EXE 文件名；
- 不联网、不遥测、不自动更新；
- Overlay 使用 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`，不抢焦点、不拦截点击；
- 诊断文件明确限定为配置、平台、显示器和注册状态。

## 九、性能结论

Release 高压基准表明，圆周栅格器相对旧的全矩形扫描在常用半径平均快 6.59–10.50 倍，在最大允许半径快 16.34 倍；三窗口持久 DIB 更新的三轮中位 P95 为 0.698 ms，三窗口全屏尺寸 Region 孔洞更新 P95 为 0.960 ms。两者保守相加仍低于 120Hz 的 8.33 ms 帧预算。

因此 P2 继续采用 Region + 持久 GDI 分层窗口。Direct2D/DirectComposition 在持续 GPU 动画、屏幕内容放大或模糊需求出现时更有价值，但当前会增加设备丢失、远程会话和驱动兼容分支，收益不足以覆盖复杂度。完整数据和限制见[渲染性能对比报告](性能对比报告.md)。
