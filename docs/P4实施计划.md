# P4 实施计划：局部放大与 GPU 渲染

P4 的目标是在不破坏 P3 轻量定位能力的前提下，增加默认包含指针、可独立于暗化遮罩使用的局部内容放大镜。主技术路线见 [ADR 0002](adr/0002-local-magnifier-rendering.md)。

## 产品原则

- 局部放大镜默认包含指针；不能正确合成时安全降级，不显示两份指针。
- 暗化遮罩可选。设置面板提供“聚焦”“放大”“聚焦 + 放大”三个可理解预设。
- “只放大指针”暂时保留，镜片启用时由镜片接管，关闭镜片后恢复原设置。
- 镜片默认使用高对比双描边，不能只靠颜色表达边界；系统启用减少动态效果时关闭波纹和非必要边缘过渡。
- 不记录或导出屏幕内容，不抢焦点、不拦截点击、不修改系统光标方案。

## P4.0 技术基础与可行性

- 建立独立的 GPU 捕获模块边界，不让 DXGI/D3D 类型泄漏到输入与配置模型。
- 枚举 DXGI 适配器和输出，并把 `HMONITOR` 映射到正确输出。
- 在正确适配器上创建带 BGRA 支持的 D3D11 设备和 `IDXGIOutputDuplication`。
- 以零超时获取、释放一帧，覆盖超时、访问丢失、模式不支持、会话断开和并发上限。
- 增加不保存像素的捕获诊断与生命周期测试替身。

出口：VS2026/v145 Debug、Release 构建通过；无镜片时不创建设备、不启动轮询，P3 行为和空闲占用不变。

## P4.1 镜片 GPU 合成

- 从活动输出纹理裁剪鼠标周围源区域，按倍率缩放到镜片目标纹理。
- 使用圆形和大圆角矩形裁剪，绘制深浅双描边、轻阴影和可关闭的边缘高光。
- 用 composition swap chain + DirectComposition 呈现透明、无激活、点击穿透镜片窗口。
- 对本程序捕获相关窗口设置 `WDA_EXCLUDEFROMCAPTURE`，失败时报告并避免无限递归。
- 镜片跨显示器时先切换活动输出；首版不把两块输出拼成一张跨缝镜片，边界采用夹取或受控迁移。

出口：普通桌面持续显示无递归、无明显撕裂；稳定态只在镜片可见时保持必要帧循环。

## P4.2 指针合成与视觉仲裁

- 解析 Desktop Duplication 的彩色、单色和 masked-color 指针形状。
- 区分指针已在桌面帧内和需要单独合成两种情况，确保只绘制一次。
- 正确应用 AND/XOR 语义，覆盖亮底、暗底 I 形文本光标。
- 镜片接管时停用 P3 放大光标副本；系统指针隐藏失败时回退到不会产生双指针的组合。
- 定义镜片、暗化孔、描边、波纹和十字线的稳定 Z-order。

出口：普通箭头、I 形、链接手形、调整大小和至少一种自定义彩色指针通过亮暗背景人工测试。

## P4.3 设置、TOML 与诊断

计划配置：

| 节/键 | 默认值 | 说明 |
| --- | --- | --- |
| `overlay.dim_enabled` | `true` | 是否启用全屏暗化遮罩 |
| `magnifier.enabled` | `false` | 是否启用局部内容放大镜 |
| `magnifier.zoom_percent` | `200` | 125–400 |
| `magnifier.diameter_dip` | `280` | 160–640 DIP |
| `magnifier.shape` | `"circle"` | `"circle"` 或 `"rounded_rectangle"` |
| `magnifier.follow_mode` | `"centered"` | 首版仅实现热点居中，预留偏移镜片 |
| `magnifier.edge_effect` | `"subtle"` | `"off"` 或 `"subtle"`，不默认几何畸变 |

- 设置面板将定位模式放在同一分组，联动禁用无效依赖项。
- 恢复默认、应用、确定、取消和旧 TOML 迁移继续保持事务语义。
- 诊断增加后端可用性、适配器/输出标识、帧格式、最近失败类别、递归排除状态和设备重建次数；不包含像素、截图或指针坐标。

## P4.4 性能、恢复与真实硬件

- 记录首次设备创建、首次可见帧、稳定帧 P50/P95、显存和进程工作集。
- 验证 60Hz 与 120Hz 节拍，不以忙循环追求刷新率。
- 验证显示器插拔、分辨率/DPI/方向变化、睡眠恢复、Explorer 重启和 D3D 设备移除。
- 记录 HDR 色彩、RDP、受保护内容、独占全屏及企业捕获策略行为。
- 对不可用环境保留聚焦模式，不能因为镜片失败留下黑窗、隐藏光标或失去托盘退出入口。

## 阶段出口

1. Debug、Release 全量构建和 CTest 通过。
2. P3 定位路径回归通过，镜片关闭时没有新增持续 GPU/CPU 活动。
3. 按《P4 验收清单》完成可用硬件范围内的真实桌面验收，未覆盖项明确记录。
4. 完成性能与故障恢复审计后创建签名 annotated `p4` 标签。
