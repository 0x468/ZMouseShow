# P4 局部放大镜验收清单

## 一、模式与基础体验

- [ ] “聚焦”只显示 P3 暗化、孔洞及所选定位效果，不创建局部放大镜。
- [ ] “放大”不暗化桌面，只显示局部放大镜，也能迅速识别鼠标位置。
- [ ] “聚焦 + 放大”同时工作，镜片、孔洞和描边位置一致且层级稳定。
- [ ] 镜片关闭时，“只放大指针”继续按 P3 设置工作；镜片打开时不会出现额外放大副本。
- [ ] 触发、关闭、暂停、托盘菜单和设置窗口生命周期与 P3 一致。

## 二、镜片视觉

- [ ] 圆形与大圆角矩形边缘平滑，在纯白和深色背景均可辨认。
- [ ] 倍率 125%–400%、尺寸 160–640 DIP 的源区域和目标区域计算正确。
- [ ] 镜片边缘只有受控高光/羽化，没有默认桶形畸变或令人不适的持续运动。
- [ ] Windows 减少动态效果设置生效时，波纹和非必要过渡关闭。
- [ ] 镜片靠近屏幕边缘和跨屏移动时没有越界、黑色随机纹理或坐标跳跃。

## 三、指针正确性

- [ ] 镜片内默认包含指针，屏幕上只看到一个具有明确热点的有效指针。
- [ ] 普通箭头、I 形文本、链接手形、水平/垂直调整大小光标形状正确。
- [ ] I 形文本光标在亮色输入框中为深色、在深色背景中为浅色，AND/XOR 语义正确。
- [ ] 指针形状变化和移动可以在桌面内容不变时独立更新。
- [ ] 捕获或隐藏系统指针失败时安全回退，不遗留隐藏光标。

## 四、性能与资源

- [ ] 镜片关闭时不保留 Desktop Duplication 会话，不运行持续捕获定时器，空闲 CPU 与 P3 相当。
- [ ] 镜片显示时无持续 GPU→CPU 帧回读，普通 2K 桌面动画主观流畅。
- [ ] 60Hz 和 120Hz 屏幕上没有明显撕裂、周期性卡顿或忙循环导致的高 CPU。
- [ ] 首次启用延迟、稳定帧 P50/P95、显存和工作集记录在性能报告中。

## 五、恢复与兼容性

- [ ] 显示器插拔、DPI/分辨率/方向变化后镜片恢复到正确输出。
- [ ] 睡眠恢复、锁屏返回和桌面切换引发 `DXGI_ERROR_ACCESS_LOST` 后自动重建。
- [ ] RDP、受保护内容、独占全屏、并发复制上限或企业策略拒绝时安全关闭镜片并保留聚焦模式。
- [ ] 本程序窗口不会被递归捕获形成镜厅效果；排除失败有诊断且不无限放大自身。
- [ ] 退出、崩溃安全路径和设备移除后不留下黑窗或隐藏系统指针。

## 六、隐私与发布

- [ ] 诊断不包含屏幕像素、截图、指针坐标、按键历史或鼠标轨迹。
- [ ] 发布仍为单个 x64 EXE，不要求管理员权限或第三方运行时 DLL。
- [ ] VS2026/v145、CMake 4.4 的 Debug/Release 全量构建和 CTest 通过。
- [ ] 创建 `p4` 标签前记录真实多屏、混合 DPI、HDR、RDP 与刷新率矩阵中所有未覆盖项。
