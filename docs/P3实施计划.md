# P3 实施计划：稳定性与交互打磨

P3 不扩张产品边界，集中处理真实桌面反馈中的触发生命周期、视觉语义和设置可理解性。阶段完成条件是自动化回归通过，并由目标 Windows 11 桌面完成候选版人工验收。

## P3.1 触发生命周期

- 晃动触发后在效果结束时重新武装，不要求重新开关选项。
- 定位效果可见或激活请求排队时，不重复执行晃动激活。
- 自定义组合键和双击 Ctrl 的释放、自动重复不关闭刚显示的效果；新的非触发按键才关闭。
- 托盘菜单和设置窗口打开期间禁止新触发，进入前隐藏效果，退出后同步物理按键与鼠标状态。

提交：`2b07464 fix: stabilize overlay input lifecycle`

## P3.2 视觉语义与渲染

- 放大光标显示前临时隐藏系统光标，失败时保留原光标而不显示第二份，所有正常关闭路径恢复系统光标。
- 高亮描边和波纹跟随圆形、圆角方形或菱形孔洞。
- 十字定位线采用黑色外沿和白色内芯。
- 保留旧圆形栅格路径的像素回归，并对三种形状执行 Release 性能基准。

提交：`f43f984 feat: align locator visuals with spotlight shape`

## P3.3 设置体验与持久化

- 晃动开关右侧增加 1–10 灵敏度滑条；关闭晃动时不可操作。
- 灵敏度只映射主要累计位移阈值，其它算法参数继续作为 TOML 高级项，避免一个滑条隐式改变多个判断维度。
- 增加“恢复默认配置”，重置可见选项和高级参数，但遵循确定、取消、应用事务语义。
- 设置保存补齐隐藏的超时、双击 Ctrl 和晃动参数，确保全局恢复在重启后仍然有效。
- 保留 TOML 注释、未知字段和未知表，并继续使用同目录临时文件加原子替换。

## 阶段出口

1. VS2026/v145 的 Debug、Release 全量构建通过。
2. 两种配置的全部 CTest 通过，渲染性能不超过 120Hz 的 8.33ms 帧预算。
3. 按《P3 验收清单》完成人工桌面验证。
4. 修复验收问题后创建 `p3` 标签。
