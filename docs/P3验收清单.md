# P3 候选版验收清单

请优先使用 `out/build/vs2026-x64/Release/ZMouseShow.exe`，退出旧实例后再启动候选版。测试前可备份同目录的 `ZMouseShow.toml`。

## 一、触发可靠性

- [ ] 连续执行至少 10 次晃动触发，每次关闭效果后都能再次触发，不需要重新开关晃动。
- [ ] 按住左键、右键或中键晃动均不触发；释放后从新的轨迹开始识别。
- [ ] 效果已显示时继续晃动不会重复启动波纹或叠加窗口。
- [ ] `Ctrl+Alt+F11` 触发后依次释放 F11、Ctrl、Alt，效果都不立刻消失；按一个新的普通键后才关闭。
- [ ] 双击 Ctrl 后剩余的 Ctrl 释放不会关闭效果，`Ctrl+C`、`Ctrl+V` 不误触发。

## 二、托盘与设置模态交互

- [ ] 打开托盘右键菜单前若有效果，效果先完整隐藏，不出现只剩白圈或闪烁。
- [ ] 托盘菜单打开时按快捷键或晃动均不触发；关闭菜单后可正常重新触发。
- [ ] 设置窗口打开时不触发定位效果；关闭后不残留按键或晃动历史。

## 三、视觉效果

- [ ] 启用放大光标后只看到一个指针；关闭效果、取消放大、退出程序后系统光标立即恢复。
- [ ] 分别选择圆形、圆角方形和菱形，透明孔、高亮描边和启动波纹三者形状一致。
- [ ] 关闭“高亮描边”后不再存在常驻轮廓，启动波纹仍按选定形状播放。
- [ ] 十字定位线在纯白和深色背景上都清楚可见。
- [ ] 动画在目标 2K 120Hz 显示器上主观流畅，无明显缩放跳帧。

## 四、设置与 TOML

- [ ] 未启用晃动时灵敏度滑条不可操作；启用后可在 1–10 调整并显示当前数字。
- [ ] 灵敏度 5 与原默认手感一致；提高数字更容易触发，降低数字更难触发。
- [ ] 修改灵敏度后点“应用”，退出并重启，设置与手感保持。
- [ ] 点击“恢复默认配置”后再点“取消”，原设置不变。
- [ ] 点击“恢复默认配置”后点“应用”，所有可见项和高级 TOML 参数恢复默认，重启后仍保持。
- [ ] 登录自启动开关继续与 Windows 11“启动应用”页面一致。

## 五、回归与诊断

- [ ] 重复启动仍只有一个实例和一个托盘图标。
- [ ] `--simulate-displays` 仍可切换三种形状。
- [ ] 导出诊断仍生成 `ZMouseShow-diagnostics.txt`，且不包含按键历史、鼠标轨迹或屏幕内容。

发现问题时请记录：触发方式、是否打开托盘/设置、当前形状与视觉开关、是否全屏、显示器刷新率，以及问题发生前最后一次操作。

若触发无效，请在问题仍处于现场时通过第二个进程运行 `ZMouseShow.exe --diagnostics`，或从托盘导出诊断，并附上 `activation_pending`、`overlay_visible`、`tray_menu_open`、`settings_dialog_open` 与 `custom_hotkey_registered` 五项。报告不含输入历史、鼠标坐标或屏幕内容。
