# P4 局部放大镜性能报告

测试日期：2026-08-16。候选程序使用 Visual Studio 2026 / MSVC v145 / CMake 4.4 Release 构建。

## 本机结果

测试适配器为 NVIDIA GeForce RTX 4060 Ti，输出为 `\\.\DISPLAY1`，Desktop Duplication 帧格式为 BGRA8。`zmouse_magnifier_benchmark` 在 280 DIP、200% 圆形镜片下运行 300 个 8 ms 节拍，结果如下：

| 指标 | 结果 |
| --- | ---: |
| D3D11 设备与复制会话创建 | 157.133 ms |
| 首个可见镜片帧 | 174.578 ms |
| 渲染节拍 P50 | 0.749 ms |
| 渲染节拍 P95 | 1.456 ms |
| 进程工作集 | 48.660 MiB |

P95 低于 120Hz 的 8.33 ms 帧预算。正常镜片路径在 GPU 纹理与 DXGI 表面之间完成裁剪、缩放和呈现，没有持续 GPU 到 CPU 帧回读；基准只读取进程内存计数，不读取屏幕像素。

## 生命周期与空闲

- 镜片配置默认关闭；关闭时不创建 D3D11 设备、不建立 Desktop Duplication 会话、不轮询帧。
- 只有定位效果可见且镜片启用时建立当前输出会话；关闭、暂停、设置窗口、显示变化和退出会释放会话。
- 获取帧使用 `AcquireNextFrame(0)`；没有新帧时立即返回，由现有等待定时器控制节拍，不使用忙循环。
- 失败重试至少间隔 1 秒；捕获排除失败直接关闭镜片，避免递归画面。

## 未覆盖矩阵

当前机器只直接覆盖单输出 NVIDIA / BGRA8 桌面。以下项目需要对应硬件或会话继续人工验证，不能由本次数据外推：

- 60Hz/120Hz 混合刷新率和真实跨屏迁移；
- 混合 DPI、旋转显示器、热插拔和睡眠恢复；
- HDR 桌面、集成显卡和跨适配器多屏；
- RDP、安全桌面、受保护内容、独占全屏和企业捕获策略；
- 显存占用的驱动级精确统计。
