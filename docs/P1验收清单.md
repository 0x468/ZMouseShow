### 3.2 晃动触发体感

1. 从托盘启用“晃动触发（实验）”。
2. 在所有鼠标按钮均释放时，快速左右摆动三至五次，确认能触发。
3. 按住左键拖动、按住右键操作和按住中键移动，确认均不触发。
4. 快速单向移动到屏幕另一侧，确认不触发。
5. Overlay 已显示时继续晃动，确认不会再次闪烁、重新淡入或延长触发队列。
6. 分别用常用鼠标与触控板测试，记录误触和漏触。

默认参数：

```toml
[shake]
interval_ms = 1000
minimum_distance = 1000.0
minimum_path_to_diagonal_ratio = 4.0
minimum_reversals = 3
cooldown_ms = 800
```

若明显难以触发，依次尝试将 `minimum_distance` 调至 `800.0`、将路径比例调至 `3.5`，最后才将时间窗调至 `1200`；不要同时修改多个参数。若容易误触，按相反顺序恢复或提高阈值。

结果：`待验收`
