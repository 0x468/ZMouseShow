# ZMouseShow 使用说明

## 一、部署与启动

ZMouseShow 是单个绿色 EXE，不需要管理员权限或安装程序。将 `ZMouseShow.exe` 放到一个允许当前用户写入的目录后直接运行即可。设置、默认配置和诊断文件需要写入 EXE 同目录；如果公司策略禁止该目录写入，请移动到获准的个人工具目录，或用 `--config` 指向可写的 TOML 文件。

程序保证同一登录会话只运行一个实例。重复启动不会留下多个托盘图标；使用 `ZMouseShow.exe --settings` 重复启动时，已有实例会打开或前置设置窗口。

## 二、定位鼠标

三种触发方式相互独立，可以同时启用，但同一时刻只会接受一个显示请求。

### 双击 Ctrl

默认启用左 Ctrl。需要完整地“按下、释放、按下、释放”两次，且时间间隔符合配置。中间出现其它键、鼠标按键或滚轮输入会取消本轮识别，因此 `Ctrl+C`、`Ctrl+V`、组合键操作或按住 Ctrl 工作不会误触发。可在设置中选择左 Ctrl、右 Ctrl 或任一侧。

### 自定义组合键

默认组合为 `Ctrl+Alt+F11`，但该触发源默认关闭。启用后程序先验证整组组合键，再用 Windows 全局热键注册探测占用；冲突或保存失败时保留上一组有效设置。它和双击 Ctrl 不互斥，自定义组合键不可用时双击 Ctrl 仍可继续使用。

冲突检测只能确认 Windows 全局注册层面的占用，不能知道每个前台程序内部定义的普通快捷键。F12、无修饰的普通键和常见高风险组合会被拒绝或警告。

### 鼠标晃动

晃动触发默认关闭。它只在左键、右键、中键均释放时统计快速反向移动；拖拽、框选、绘图或按住鼠标键操作不会触发。定位效果已经显示或处于启动请求阶段时，不再重复执行晃动激活判断。设置中的灵敏度为 1–10，数字越高，触发所需的累计位移越小；默认 5 与原来的 1000 位移阈值一致。

## 三、显示与关闭效果

触发后按设置显示“聚焦”“放大”或“聚焦 + 放大”。聚焦模式在各显示器建立暗化层并留下透明高亮区域；放大模式只显示鼠标附近的局部内容镜片；组合模式同时显示两者。可选视觉层包括：

- 与高亮孔同形状的稳定描边：默认开启；
- 向外扩散并淡出的单次波纹：默认开启；
- 带深色外沿和白色内芯的十字定位线：默认关闭；
- 当前系统光标的放大显示：默认关闭，可设置为 125%–400%；显示期间临时隐藏原光标，避免出现两个指针。
- 局部内容放大镜：默认关闭，可设置 125%–400%、160–640 DIP、圆形或大圆角矩形；镜片启用时停用旧的放大光标副本。

镜片使用当前显示输出上的 Desktop Duplication 帧，并通过 GPU 裁剪、缩放和呈现。所有本程序视觉窗口必须成功设置捕获排除；排除、捕获设备或桌面会话不可用时，镜片安全关闭并保留聚焦效果。程序不会为了镜片隐藏仍在使用的系统指针，因此失败路径不会留下隐藏指针。

高亮孔洞支持圆形、圆角方形和菱形；稳定描边和启动波纹始终使用相同形状。出现动画是稳定描边淡入加向外扩散波纹，不再使用“大圆从外向内收缩”的方案。

默认常驻显示，直到发生按键、鼠标按键、滚轮、暂停或退出。自动超时默认关闭；启用后，空闲超时和最大持续时间共同限制显示时间。

## 四、设置窗口

右键托盘图标选择“设置”，或运行 `ZMouseShow.exe --settings`。设置窗口支持鼠标和键盘操作；各控件具有唯一访问键，`Tab` 可按顺序移动焦点。

“应用”会先验证输入、探测自定义组合键冲突、更新当前用户自启动状态并原子保存 TOML，全部成功后才替换当前运行时设置。“确定”执行同样操作后关闭；“取消”只放弃尚未应用的修改，已经应用的内容不回滚。

“恢复默认配置”会把面板内选项和 TOML 高级参数一起恢复为默认草稿，但不会立即保存；继续点击“应用”或“确定”才会持久化，直接“取消”可以放弃恢复。托盘菜单或设置窗口打开期间，触发输入会被有意屏蔽并清空候选状态，关闭后从新的按键或鼠标轨迹开始识别。

排除程序只填写 EXE 文件名，例如：

```text
game.exe; presenter.exe
```

不接受完整路径。名称不区分 ASCII 大小写，保存时转为小写并去重，最多 64 个。

## 五、全屏抑制

- 自动：默认值。当前台窗口覆盖整块显示器或限制鼠标范围时，只抑制容易误触的鼠标晃动；双击 Ctrl 和自定义组合键仍可明确唤醒。
- 关闭：不根据全屏或鼠标捕获状态抑制触发。
- 严格：全屏或鼠标受限时抑制所有触发。

这不是“识别游戏”。它根据前台窗口边界和鼠标限制状态进行启发式判断，窗口化无边框、远程桌面或特殊渲染程序可能与预期不同。需要百分之百屏蔽的程序应加入排除列表；排除列表优先于全屏策略并屏蔽全部触发。

## 六、登录自启动

勾选“登录后自启动”后，程序在当前用户的以下位置登记自身完整路径：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ZMouseShow
```

不写系统范围注册表、不请求管理员权限。取消勾选会删除该值。公司组策略或安全软件可能拒绝写入，此时设置不会伪装成成功；诊断报告会同时记录 TOML 期望值和实际登记状态。移动 EXE 后应重新打开设置并应用一次。

## 七、TOML 配置

默认路径为 EXE 同目录的 `ZMouseShow.toml`。文件不存在时使用内置默认值；托盘菜单可导出完整默认文件，且不会覆盖已有文件。高级时间窗口、晃动阈值等字段仍可直接编辑 TOML，然后从托盘选择“重新加载配置”。

旧配置无需手工迁移。缺失字段使用当前默认值，首次从设置窗口保存时补入新字段；原有注释、未知字段和未知表继续保留。语法错误的 TOML 会整份拒绝，保存失败不会破坏原文件。

完整字段、范围和默认值见[需求规格说明书](需求规格说明书.md)。

## 八、命令行参数

| 参数 | 作用 |
| --- | --- |
| `--settings` | 启动后打开设置；已有实例运行时转交给已有实例。 |
| `--config <路径>` | 使用指定 TOML 文件。 |
| `--simulate-displays` | 打开单屏开发用的三显示器交互预览，不进入正常常驻流程。 |

`--simulate-displays` 只增加一次命令行判断和独立预览代码路径，正常运行时不会创建模拟窗口、定时器或额外后台线程。

## 九、排查问题

- 没有托盘图标：先检查任务管理器中是否已有实例；Explorer 重启后程序会重新添加托盘图标。
- 双击 Ctrl 无效：确认选择了正确 Ctrl 侧，完整释放两次，且过程中没有其它输入。
- 晃动无效：确认已启用、鼠标按键均释放、程序未暂停，并检查全屏抑制和排除列表；可逐级提高灵敏度，不建议同时手改多个高级阈值。
- 自定义组合键无效：打开设置重新应用；若提示占用，更换组合或恢复默认。
- 设置无法保存：确认 EXE/TOML 所在目录可写，公司策略没有阻止注册表或文件操作。
- 特效不流畅：先尝试关闭放大光标、十字线或波纹，并导出诊断；混合 60Hz/120Hz 多屏仍需真实目标硬件验证。
- 镜片未出现：先确认选择“放大”或“聚焦 + 放大”；RDP、安全桌面、受保护内容、企业捕获策略或复制会话上限可能拒绝捕获，诊断中的 `capture.last_failure` 会记录失败类别。
- 任务栏未暗化：如果刚刚点击并激活了任务栏，Windows Shell 可能将它保持在其它 Topmost 窗口之上。程序不会通过抢焦点、隐藏任务栏或未公开 API 强制覆盖它。
- I 形放大光标颜色不同：部分单色文本光标使用依赖背景的 XOR 蒙版，固定 Alpha 放大副本可能显示为白色；关闭“放大光标”不影响其它定位效果。

托盘菜单“导出诊断”会生成 `ZMouseShow-diagnostics.txt`，包含有效配置、显示器边界、DPI、触发请求/Overlay/托盘菜单/设置窗口状态、捕获适配器/输出/格式、失败类别和设备重建次数，不记录按键历史、鼠标轨迹、鼠标坐标、屏幕像素或截图。
